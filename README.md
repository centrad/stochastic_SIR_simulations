# stochastic_SIR_simulations

# Work in progress - content may change

Simulations of Markov SIR epidemic models with heterogeneous
transmission probabilities, contact rates,
and group sizes.

Developed as part of unpublished thesis work.

## Requirements

R and the dplyr package.

## Attribution

The Gillespie-type algorithms were adapted
from code by Michael Höhle:

https://github.com/mhoehle/STA427_SM4IDE
